# LifeOS Trailer V2 — Plan

**Tone:** polished + cinematic (Apple-announcement restraint)  
**Duration:** 34s · 1920×1080 · 30fps  
**Angle:** LifeOS exists because life is observations that need personal context before a recommendation — not another dashboard of apps.

## What is real (must not invent)

- Environments: Life, School, Work, Study Abroad, Treasury, Mastery
- Now capture `/t`, Tasks, Focus (timer/checklist/notes), Calendar, Library/Brain
- Architecture in `lib/lifeos-kernel.ts`: Observations → Personal Context → Recommendation / Daily Briefing
- Now UI: “Good next choices” task recommendations
- Briefing UI: Focus Today + Also Notice
